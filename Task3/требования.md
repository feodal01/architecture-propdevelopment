# Безопасность
- шифрование каналов (TLS 1.2/1.3)
- недопустить передачу персональныз данных, где это не требуется, наладить соответствие 152-ФЗ
- наверняка придется хранить биометрию - лица, чтобы можно было сравнивать с тем что пришло от умного устройства. Нужно организовать защищенное хранение в соответствии со всеми законами
- не хранить видеозаписи, так как на них может быть персональная информация (лица / номера и тд), хранить только срабатывание / не срабатывание по номеру как событие и данные с которыми нужно сравнивать и которые приходят от умных устройств
- умное устройство присылает данные, наш сервис проверяет доступ и отправляет ответ - да/нет, так данные не уйдут из нашего контура

# Аутентификация и авторизация
- Использовать OAuth 2.0 / OpenID Connect для взаимодействия с мобильным приложением
- JWT-токены (короткоживущие)
- Ролевая модель (обычный пользователь / администратор / суперадмин)

# Интеграция и взаимодействие
- Все запросы проходят через API Gateway PropDevelopment
- REST или gRPC API от партнёра (управление домофоном/шлагбаумом)
- Определить, кто (или какие сервисы) может подключаться к устройству и по каким портам/протоколам
- Вести логи, отслеживать и блокировать подозрительные запросы

# Мониторинг и SLA
- Health-check endpoints у партнёра и на устройствах
- Лимиты запросов (rate-limiting)
- Журналы (audit logs) с долгосрочным хранением
